# 《AI 玩法日报》网页编辑使用说明 · v2

每期从同一份《AI玩法日报_样板.html》复制出刊。报头、签筒、日历、头条双态版式、五张主题卡片和「主编的话」已定版。网页编辑负责把当期稿件填到对应栏目。

## 出一期日报

1. 复制样板，按期次命名，例如 `AI玩法日报_2026-11-29.html`。保留空白母版供下一期使用。
2. 用文本编辑器打开副本，搜索 **每期内容开始**。只填写其下方 `id="issue-data"` 的 JSON。双花括号里的文字是占位提示，正式填稿时连同括号一起替换。
3. 保存为 UTF-8，双击 HTML 预览。页面自带样式和交互，无需安装工具。使用本地配图时，把图片随 HTML 一起交付，并保持相对路径一致。

## 栏目怎么填

| 位置 | 填法 |
| --- | --- |
| 报头日期 `date` | 填真实出刊日期，格式为 `YYYY-MM-DD`，例如 `2026-11-29`。日历自动排好当月日期并标出当期。 |
| 头条 `headline` | `kicker` 填引题，`title` 填主标题，`summary` 填摘要。`paragraphs` 里每个字符串是一段正文，按稿件增减。在引题或主标题中用 `《《重点词》》` 标出要高亮的部分，例如 `让助手先做《《第一步》》`。 |
| 头条图片 | `image` 填图片网址或相对路径，例如 `images/headline.jpg`，`alt` 用一句话描述画面。有图时读者可以切换版式。没有合适配图时两项均填空字符串 `""`，本期自动采用无图版。 |
| 全球速览 `articles` | 五个固定栏目依次是 `magic` 魔法实验室、`forge` 炼丹炉前线、`cyber` 赛博游乐场、`armory` 兵器谱更新、`workshop` 齿轮与车间。把样板中 forge 下的文章对象复制到当期对应栏目，按阅读顺序排列；每张卡片预览前两条。空栏目保留 `[]`，主题标签自动置灰。 |
| 文章与签文 | 每篇填写 `title`、`summary`、`content`。正文用 `\n\n` 分段。`fortune` 写一句只有读过这篇才写得出的提醒、玩法或趣话，「宜」「忌」按内容选用。留空时自动采用摘要。「给我解签！」自动定位到这篇。 |
| 来源 `links` | 每个来源含读者看到的 `name` 和原文的完整 HTTP(S) 地址 `url`。可以填多个，无可用链接时填 `[]`。 |
| 主编的话 `editor` | `paragraphs` 放一段或几段寄语。`signature` 默认填 `RadarChief`，破折号由模板生成。 |

## v2 的填写与验收

- **头条来源**填在 `headline.links`，每项填写来源名称和原文完整网址，与速览文章的 `links` 格式相同。头条文字下方自动展示；交稿时确认每条链接指向支持该报道的原文。
- **签文**按文章选用一种口吻。建议写 `宜：先看一眼代码差异。`，提醒写 `忌：把示范结果当成自己的实测。`，也可以直接写普通句子。同一签有两条建议时可填 `宜：核对硬件型号。\n宜：记下测试条件。`。每条各占一行，宜用绿色、忌用红色。未写签文时使用文章摘要。
- **抽签预览**点击「抽取今日签」后，标题旁的签筒会在等待期间摇动，出签或关闭弹窗时停止。系统开启减少动态效果时保留文字反馈。
- **站点日历**由发布仓库接入。每期发布时把新版刊期映射到对应的正式页面；若首页换期，原刊期应改指其留存地址。用「本期 → 旧刊 → 本期」核对返回后的标题与版式，另测从旧阅读器直接打开该日期。

## RadarChief 的主编寄语

这一栏给主编留一点自由。每期任选一种口吻，也可以混用。下面三句是语气示例，选用时按当期稿件调整。

- **读后感。**「今天我最想留下的是那个替人收拾标签页的小工具。我收藏了那么多效率工具，终于有一个想来收拾它们了。」
- **无厘头的垃圾话。**「刚才签筒请了年假。我说可以，但你先把今天这根吐出来。」
- **改版或栏目介绍。**「这期给日报换了张脸。想随便逛逛，就摇一下报头旁的签筒；想直奔主题，就点速览里的卡片。」

## 全球速览的阅读入口

网格卡片最多预览两篇。点击文章标题会直接选中该篇并显示正文；点击卡片其余区域会打开该主题首篇。主题阅读模式下，主题标签与「全球速览」标题、返回按钮共用一行，窄屏可横向滑动。空主题标签继续置灰。这些交互由样板自动生成，每期只需按阅读顺序填写文章。

## 交稿前预览

- 在内容区搜索 `{{`，确认占位提示都已填完。确认报头日期、头条图片和主编署名属于本期。
- 对有两条预览的主题，点击第二条，确认详情标题与所点文章一致；返回网格后主题标签应隐藏。
- 打开「按主题阅读」，点一条文章，核对正文和来源。空主题应置灰，保留栏目名即可。
- 点报头签筒，抽一签，再点「给我解签！」核对签文对应的文章。
- JSON 使用英文双引号，多个条目之间加逗号，最后一项后面不加逗号。段落优先用数组拆分；字符串里的英文双引号写成 `\"`。正文填纯文字。如果稿件需要逐字展示 HTML 代码，内容字符串中的小于号写成 `\u003c`。

## 可直接交给网页编辑的任务说明

> 请复制《AI玩法日报_样板.html》，用当期稿件填写 issue-data，再以出刊日期另存为 HTML。沿用既定版式、配色、图标、按钮和交互。五个栏目按当期实际稿量填写，空栏目留空。签文跟随对应文章。主编的话由 RadarChief 自由发挥，可以点评本期、讲一句无厘头的玩笑，也可以介绍本期改版。交稿前按本说明预览。
