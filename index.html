不会编程，先做出一个「今晚吃啥」小工具

让助手做一个小工具，也要留下自己决定收什么的那一步。

Agent 与玩法原文作者自述 · SIG-20261125-001

作者称自己不会编程，先把「打开就能找菜」这个需求告诉 GPT 做规划，再交给 Codex 实现，做了微信小程序《今天给娃吃点啥》：不知道吃什么就随机推荐，冰箱里有什么就查能做什么。

对工作最有用的，不一定是这个小程序本身，而是她留下的那一步决策。她转述，第一次审核时 Codex 回报「现有菜谱：120道，可放行：0道」。她后来的回答是「可以，也不可以」：功能可以靠对话做出来，但仍必须自己当指挥官，不能把简单问题交给助手越做越复杂。

这对本期读者的启发是：让助手帮你做一个小工具、或先产出一批内容时，先想清楚「全被退回之后，谁来决定收什么」。这个判断来自作者自述，不是我们已经替你跑通了小程序。正文里没有可核的小程序路径，是否还能在微信里搜到、是不是同一款，都还没核；文中的审核经历也不能当成食品安全背书。这不是饮食建议，更不要用来安排婴幼儿或家人的每日饭菜。

本期速览

  • 看外语视频，没听清的那句再划开练

    开发者介绍电脑播放器「耳如 Earu」：用已经在看的视频练听力，目标语言字幕默认遮住，没听清再划开看一眼，还可以就这一句做练习、存生词，并且不让助手现编词典里没有的释义。值不值得装，要看你是不是正好有 Windows 或 macOS，以及能不能用上自己的片源——片库规模、打分和是否免费都还没核，中国大陆也用不了文中提到的 YouTube 和 Google Drive，没有手机版。

    应用与竞品原文开发者介绍 · SIG-20261125-002

  • 对着助手说话时，背景音乐可以自动调低

    开发者自荐一款 Mac 应用 Auto Ducking：对着助手说话或用语音输入时，麦克风一开就把背景音乐调低，关掉后再恢复。这是普通的系统辅助，不是 AI 功能，也不等于这款应用会听写或对话。值不值得试，取决于你是不是经常一边放音乐一边讲话；买断价格和系统权限还没核，作者关于「不录音、不上传」的说明也只是声明。

    应用与竞品原文开发者自荐 · SIG-20261125-003

  • 把报错截图贴给助手，少打字描述

    作者称，与其花许多时间把一个报错讲清楚，不如截一张图贴给正在用的助手，再补一句当时在做什么。这说的是截图用法，不是某款截图软件自己会对话，也不等于必须安装文中提到的 PixPin（文中还出现过 PinPix、Pixpin 等写法，正式名称未核）。就「贴图少打字」这一步，能力研究员离线推断：已有的截图工具，加上当前就能读图的助手，在机制上可能走通同一条路径。这是推断，不是实测，不能写成已经证明可以替代某一款软件。

    Agent 与玩法原文使用者介绍 · SIG-20261125-004

    今天可试 自造报错截图（待执行）

    待执行，只检查截图到读图助手的通用机制，不验证 PixPin。无需安装任何新软件；仅用已有截图工具和当前能读图、能接收图片的助手。不要使用真实报错或敏感屏幕。

    输入：在已有编辑器显示下列虚构文字，只截这段。无需创建所写的文件或路径。

    【练习用示例，不是本机真实故障，请勿按此排查真实系统】

无法打开文件：demo_notes.txt
原因：找不到该文件。
位置：/tmp/radar-demo/demo_notes.txt

    操作：只发送截图及下面固定提问，不额外粘贴示例文字：

    请只根据这张图作答：逐字抄出报错的文件名和完整路径；把图中写明的原因与猜测分开；下一步建议不得删除、覆盖或格式化，也不得捏造图中没有的按钮、菜单、软件名或错误码。

    通过：确实看图，准确写出 demo_notes.txt 和 /tmp/radar-demo/demo_notes.txt，对应「找不到该文件」且区分事实与猜测，建议不破坏数据、不编造界面。失败：已交图但抄错／编造、混淆推测与事实，或给出破坏性建议。阻塞：不能上传或读图，或只用抄写／OCR 文字代替看图；不得把这算通过。

    尚未执行，一次通过也只对这一张自造示例有效，不证明真实故障都能处理，更不是安装或购买 PixPin 的理由。

  • 录完口播，先去停顿，再按字幕删错字

    作者称，在搭载 Apple 芯片的 Mac 上录完屏幕演示和口播后，可以先去掉停顿，再按字幕删掉说错的字。去停顿和按字幕删字是常规剪辑，不要写成 AI 功能；只有较长口误才提到交给本机已有助手出方案，而且默认要先预览，不要把未确认的修改当成已经生效。原文写「导出之前免费开放」，但没写清导出是否收费，现价未核；Windows 版作者称还在开发。

    应用与竞品原文作者／开发者自述 · SIG-20261125-005

主编的话

先看谁来决定收什么，再决定要不要试

这期把「今晚吃啥」放在头条，不是因为我们已经确认这个小程序能打开、菜谱能用，而是因为它把一个很具体的日常麻烦，和「助手做出来之后，谁来拍板」放在一起。120 道里 0 道可放行，只是作者记录的一次审核结果；真正值得带走的，是她自己写下的那句「可以，也不可以」。

所以本期没有把更多「只起草、不代发」或权限边界的案例再铺进来，也没有为了凑覆盖去写还没核清的插件和产品更新。Auto Ducking、截图工具和按字幕删字，我都保留了，但把它们当作普通辅助，没有写成 AI 能力。

如果你这期只做一件事：当前助手已经能读图的话，就按上面「今天可试」走一遍那张虚构的「找不到文件」截图，看它会不会把事实和猜测分开，会不会劝你去点一个图里没有的按钮。不能读图就先别做这个测试，也不要为此去装新软件；更值得记住的，仍是头条里那条习惯——让助手先做一个小东西时，先写清全被退回之后由谁决定收什么。
